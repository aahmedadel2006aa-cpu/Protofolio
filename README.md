# Ahmed Adel - Portfolio

A modern, premium Full Stack Developer portfolio website with glassmorphism design, smooth animations, and advanced UI effects.

## Features

- **Responsive Design** - Works on all devices
- **Dark/Light Mode** - Theme toggle with localStorage persistence
- **Loading Screen** - Elegant loader animation
- **Scroll Progress Bar** - Visual scroll indicator
- **Typing Animation** - Rotating role titles
- **Animated Statistics** - Counter animations on scroll
- **Scroll Reveal** - Section fade-in animations
- **Custom Cursor** - Interactive cursor (desktop only)
- **Glassmorphism Cards** - Modern frosted glass effect
- **Floating Background** - Animated gradient orbs and shapes

## Setup

1. Open `index.html` in a browser or use a local server
2. To add your CV: Place your PDF in the folder and update the Download CV link:
   ```html
   <a href="your-cv.pdf" class="btn btn-primary" download>
   ```
3. Update the contact form email in the social links section
4. Add your LinkedIn URL when available

## Customization

- **Colors**: Edit CSS variables in `:root` in `styles.css`
- **Content**: Update text directly in `index.html`
- **Projects**: Add/remove project cards in the projects section
